Getting started

  1. Save either file to your computer and open it in RStudio.
  2. Run the Setup section first to install the required packages. An internet connection is needed for installation and the GENIE example.
  3. Follow the examples, then complete each Try it prompt.

If a file opens in your browser, right-click its download button and choose “Save link as…” to save it with the .R or .Rmd extension.
